Small cleanup release on top of 0.9.9b — one buggy mod out, live map improvement in, and the server
list entry gets a proper MOTD.

## ➖ Removed Mods

- **Sound Physics: Aeronautics** — pulled for being highly buggy. Sound occlusion/reverb stays gone
  until a stable build lands; ambient audio (AmbientSounds, Glaidens Audio, Create: Sound of Steam)
  is unaffected.

## 🗺️ Live Map — Train Tracks

`config/create_bluemap-server.toml` now ships the live server config with **track rendering enabled**:

- `renderTracks = true` — Create: Steam 'n' Rails track network is drawn on the BlueMap web map
- `renderCarriages` / `renderTrains` stay on
- The file also drops the stale `[general]` table header the pack shipped before — the mod writes
  these keys at top level, so the old file was being ignored and regenerated

## ⚙️ Server Settings

`server.properties` gains a MOTD — the server now shows up as **Aero Server** in the multiplayer
list instead of the default line:

```
motd=§bAero Server
```

## 📝 Notes

No mod updates in this release. The server icon (`server-icon.png`) is managed on the server itself
and is not shipped in the pack, so deploying this release leaves it untouched.

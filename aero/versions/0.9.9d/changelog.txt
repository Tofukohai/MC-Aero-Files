## 📖 Quest Book

FTB Quests ships pre-built as a config override — 4 chapters, 188 quests. Open it from the sidebar
button in your inventory.

| Chapter | Quests |
|---|---|
| Welcome | 4 |
| Create Aeronautics | 47 |
| Create | 112 |
| Combustion | 25 |

**Combustion** is written for this pack: Diesel Generators' Pumpjack, Oil Scanner and Distillation
recipes are removed (no bedrock under a floating island), replaced by a Plant Oil / Ethanol /
Black Dye Fluid → Biodiesel → Diesel chain. Quest icons ship as a Paxi resource pack.

## ⌨️ Keybinds

Keybind defaults now ship in **`config/defaultoptions/keybindings.txt`**, not `options.txt`.
DefaultOptions reads keys only from that file — the 197 `key_*` lines the pack shipped in
`options.txt` since 1.0.0 never applied. This fixes `M`, Iris reload, and Fancy Toasts reverting to
colliding binds on fresh installs.

## 🌬️ Nether Air Pressure

Paxi global datapack sets Sable `base_pressure` to **1.35** in the Nether — lift there now behaves
as if flying 75 blocks lower. Overworld deliberately untouched.

> Server operators: the datapack must exist on the server too, or Nether lift desyncs.

## ☁️ Sky Stack

Cirrus replaces vanilla clouds/sky. Cloud decks at y 217 / 281 / 345; Particle Rain's
`spawnHeightLimit` is pinned to `217` to match the lower deck.

## 🖥️ Server

- MOTD version token auto-bumped by the release script
- No proxy — direct connect

> **Server operators:** mrpack4server never prunes mods that leave the pack. Wipe the server's
> `mods/` folder before deploying, or the removed jars linger and kick clients with
> "Incompatible client".
